# Global implementation of biodiversity finance plans calls for adaptive strategies

This repository contains the data, R code, figures and tables and supporting materials for the paper:

**“Global implementation of biodiversity finance plans calls for adaptive strategies”**

The study examines the implementation of biodiversity finance instruments included in national Biodiversity Finance Plans (BFPs), drawing on data from 32 countries participating in the UNDP Biodiversity Finance Initiative (BIOFIN).

## Repository structure

- `Code/` – R scripts used for data processing, analysis, statistical modelling, and visualization.
- `Data/` – Processed data and external data used in the analyses. 
- `Figures/` – Figures generated from the analysis.
- `In paper_figures_tables/` – Final figures and tables included in the manuscript.
- `Outputs/` – Model outputs and other intermediate analytical results.
- `Tables/` – Tables generated from the analysis.
- `Rcode_biofin_paper.Rproj` – RStudio project file for reproducing the analyses.

## Reproducing the analysis

Clone or download this repository and open `Rcode_biofin_paper.Rproj` in RStudio. The scripts in `Code/` contain the code used to process the data, conduct the statistical analyses, and generate the figures and tables reported in the paper.

Relative file paths are used so that the analyses can be run from the project directory.

## Data

The repository contains the data required to reproduce the quantitative analyses presented in the paper. Details on data sources, variable construction, and analytical methods are provided in the manuscript.
